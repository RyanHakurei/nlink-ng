# Changelog

## 1.0.0

Native linker for TI calculators.

### Windows

nlink-ng runs on Windows. Run the installer, then open nlink-ng. In Command Prompt, `n-link.exe ls /` lists the calculator.

### Files

Drag files and folders from the calculator onto your computer.

### Linux

Install the AppImage with `chmod +x`, then run it. The command-line tool is `n-link`.

### Android (experimental)

USB-OTG app for 64-bit phones and tablets.

TI-84 series support is untested. I do not have that hardware.
